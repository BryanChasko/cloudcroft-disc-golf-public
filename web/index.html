    How this scorecard gets built

    1. Walk the course. At each tee an averaged GPS point joins a photo of the tee sign and a note — par, distance, mando, out-of-bounds. This one is real: community tee 2, par 3, 245 ft, mando right, fence-line out of bounds right.
    2. Hand off the raw day. The survey app's project backup carries every point, note, and attached photo in one file. A small extractor turns it into open GeoJSON — no app lock-in.
    3. Validate. Points must land inside the course boundary; named tees and baskets must parse. Gaps are reported, never silently invented — unsurveyed holes stay visibly blank, like the scaffolds in the table above.
    4. Build the holes. Tee-to-basket lines, elevation, and a plays-like distance come from the 1 m terrain model, cross-checked against the tee signs.
    5. Publish. The map, walkthrough, and this card read the same data files, so the next field day lights up new holes with no code change.
