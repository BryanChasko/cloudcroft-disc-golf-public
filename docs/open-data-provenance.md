## integration spec for the normals callout (story/map owners)

zero-conflict by design: this change adds data + script + tests only.

1. deploy `dataset/climate-normals-cloudcroft.json` next to the other
   bundled data copies (same path pattern as `web/src/config.ts` `DATA`).
2. story page: one callout in the dataset section, suggested copy:
   "at 8,676 ft the season is short: july averages 60.1 F (high 72.2 F)
   with 5.53 in of monsoon rain; january averages 30.7 F with 13.1 in
   of snow. NOAA 1991-2020 climate normals, Cloudcroft station
   USC00291931, via the Registry of Open Data on AWS."
3. map page (optional): a "typical month" line in the hole-table
   footer reading the current month from the JSON; no new fetch path,
   bundle the file like `survey-assets.json`.
4. attribution line wherever rendered: "climate: NOAA NCEI U.S.
   Climate Normals 1991-2020 (Registry of Open Data on AWS)".
